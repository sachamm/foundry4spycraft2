# Sample agent artwork

17 original character portraits made with the built-in OpenAI image generator. Each has a 512 × 512 WebP portrait and a matching 256 × 256 circular WebP token with transparency, generated as an edit of its portrait to preserve identity. The set includes Bracken, the Scout’s animal partner.

See [the character gallery](catalog.html) and [the generation prompts and hashes](generation-prompts.json). High-resolution source images are not included in the install package.
