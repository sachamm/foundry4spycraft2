# Where the Trains Run Under

The bundled eleven-track album appears in the Playlists tab on the next active GM launch, once per world. It is also available from the **Soundtrack** compendium for manual import. Playback is sequential, with manual ordering and no individual-track repeats; nothing starts automatically.

1. Where the Trains Run Under
2. Tremolo Lounge
3. Muted Brass
4. Shadowed Motif
5. Clipped Minor Motif
6. Ticking Motif
7. Shadowy Ticking
8. Ticking Shadows
9. Clipped Tremolo
10. Shadow Pulse
11. Run It Quiet

These OGG Vorbis assets were supplied by the project owner for inclusion with the system. They use Vorbis quality 6 (approximately 192 kbps variable bitrate), preserving the supplied sample rate and channels, without trimming or normalization. The sequence is an editorial arrangement based on the track titles, with the requested opening and closing tracks.

The source Playlist document is `src/data/soundtrack.json`; `npm run build` packages it and its embedded sounds into `packs/soundtrack`. Asset paths are relative to the installed system and do not depend on a particular world or computer.
