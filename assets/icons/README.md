# Compendium icon artwork

157 original icons generated with the built-in OpenAI image generator and compressed to 128 × 128 WebP. Related models, Caliber variants and feat progressions share suitable artwork. The complete set occupies 247,966 bytes; each file is below 16 KiB.

[Browse the icon gallery](catalog.html) or inspect the [generation prompts and hashes](generation-prompts.json). Assignments for all 1,921 catalog items and 36 GC tables are maintained in `src/data/compendium-icons.json`. NPC common supplies and ammunition use the same icon library. Portraits, circular NPC tokens and scene backgrounds are separate artwork.

No rulebook illustrations or third-party icon sets were used. Fresh compendium imports use the new icons; existing world items retain their current artwork.
