# Core NPC artwork

Twenty original painted portraits and twenty matching circular tokens, created with the built-in OpenAI image generation tool. Each token was generated from its corresponding portrait to preserve the character's appearance. No third-party artwork or rulebook illustrations were used.

The PNG originals are retained without resizing. Tokens have transparent pixels outside the circular charcoal-and-brass border. Names and labels are not baked into the artwork. Exact prompts, image hashes and the portrait-to-token references are recorded in [generation-prompts.json](generation-prompts.json).

The Core NPC Templates compendium uses each portrait as its actor image and the matching token as its prototype-token texture. Import a fresh template for these defaults. Existing world actors retain their images, and TL packages preserve customized artwork. These appearances are examples for reusable roles; the GC can change either image.
