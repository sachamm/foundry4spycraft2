# Sample environments

Three original AI-generated backgrounds, created with the built-in OpenAI image generation tool using the running world's drawing-based encounter test beds as layout guides. No third-party map art was used. Prompts are retained in src/scenes/generation-prompts.json in the source repository.

Open **Compendium Packs → The Field Agent's Handbook → Sample Scenes**, then import the scenes you want into your world. These are environments with no actor or token dependencies. They do not create characters or encounters.

- **Warehouse Breach:** crate stacks block sight and movement, low pallets block movement only, loading door and office door start closed.
- **Night Infiltration:** dark courtyard with security office, locked server-room door, service exit and local lights. Give your own tokens appropriate vision before playing.
- **Embassy Reception:** warm reception hall, office and service kitchen, closed doors, and a low bar that blocks movement while allowing sight.

All scenes use a 5-foot square grid, 1536 × 1024 backgrounds, and Foundry v14 levels, walls and lighting. Toggle the grid to taste. Furniture other than the explicitly walled cover is decorative; adjudicate cover as appropriate. No actors, NPCs, world journals, user IDs, or original test-bed drawing labels are included.

WebP quality 82 preserves the original pixel dimensions. Total background size: 749,470 bytes. Configure the scene darkness and lights to suit the session; the night map also has a blue night palette in its artwork.

New empty worlds receive these three scenes automatically on the first GM launch. Setup runs once, so deleted samples stay deleted. Existing worlds are left as they are; import samples from the compendium when wanted. Interrupted setup resumes on the next GM launch.
