# Button icon atlas

Generated with the built-in image generator. The PNG is a transparent 4 × 4 atlas consumed directly by CSS; no runtime image service is required.

Row order: add, edit, remove, confirm; roll, attack, damage, defense; browse, refresh, mission, heal; chat, continue, settings, cancel.

This original atlas is retained as an asset. The expanded function atlases and their catalog are in `assets/ui/functions/`. Existing names, tooltips, event handlers, disabled state and pressed state remain on the original controls. Stat displays, tabs and Foundry window header controls retain their existing presentation.
